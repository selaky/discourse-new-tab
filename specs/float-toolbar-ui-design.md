# 悬浮工具栏界面设计规范

## 悬浮工具栏样式

### 容器
```css
- 布局：竖排（垂直堆叠）
- 背景：半透明毛玻璃效果
  - 浅色主题：rgba(255, 255, 255, 0.9) + backdrop-filter: blur(12px)
  - 深色主题：rgba(30, 30, 30, 0.9) + backdrop-filter: blur(12px)
- 圆角：12px
- 阴影：0 4px 20px rgba(0, 0, 0, 0.15)（浅色）/ 0 4px 20px rgba(0, 0, 0, 0.4)（深色）
- 内边距：12px
- 按钮间距：8px
- 默认位置：右下角（距底部 80px，距右边 24px）
- 扩展性：支持任意数量按钮，按钮过多时容器最大高度限制在视口 80%，内部可滚动
```

### 圆形按钮
```css
- 形状：正圆形
- 尺寸：48px × 48px
- 图标尺寸：24px × 24px，居中
- 背景色：
  - 默认：transparent
  - 悬停：var(--dnt-bg-hover)
  - 激活：var(--dnt-primary)
- 图标颜色：
  - 默认：var(--dnt-text-secondary)
  - 悬停：var(--dnt-text-primary)
  - 激活：#ffffff
- 过渡：all 0.2s cubic-bezier(0.4, 0, 0.2, 1)
- 悬停效果：transform: scale(1.08)
- 触摸反馈：active 状态 transform: scale(0.95)
```

### 拖拽手柄
```css
- 位置：容器顶部
- 形状：圆角矩形条
- 尺寸：32px × 4px
- 背景色：var(--dnt-text-muted)
- 圆角：2px
- 透明度：0.4
- 悬停透明度：0.7
- 光标：grab / grabbing
- 固定模式：display: none
```

### 按钮图标映射

| 功能 | 图标视觉 | 说明 |
|-----|---------|------|
| 拖拽手柄 | 两列三点网格 | 仅在非固定模式显示 |
| 回到顶部 | 向上箭头 | 简洁的向上箭头 |
| 模式切换 | 动态图标 | none: 空心圆，topic: 横线列表，all: 网格方格 |
| 打开设置 | 齿轮 | 标准设置图标 |

**模式切换图标设计说明：**
- none（不后台打开）：空心圆 - 表示"关闭/无"
- topic（仅主题帖）：3条横线列表 - 表示"部分内容"（与现有悬浮球保持一致）
- all（全部后台打开）：2×2网格方格 - 表示"全部内容"（与现有悬浮球保持一致）

### Tooltip 提示
```css
- 位置：按钮左侧（向左偏移 8px）
- 背景：var(--dnt-bg-dialog)
- 文字颜色：var(--dnt-text-primary)
- 边框：1px solid var(--dnt-border)
- 圆角：6px
- 内边距：6px 12px
- 阴影：0 2px 8px rgba(0, 0, 0, 0.15)
- 字号：13px
- 箭头：朝右的小三角
- 触发：悬停 500ms 后显示
```

## 设置界面设计

### 布局结构
```
悬浮工具栏（新增分类）
├── 基础设置
├── 功能管理
└── 模式切换设置（条件显示）
```

### 基础设置区块

#### 标题
```
功能名称：基础设置
```

#### 内容布局
```html
[开关行 1] 显示悬浮工具栏
           说明：关闭后工具栏将完全隐藏

[开关行 2] 固定位置
           说明：禁用拖拽，锁定工具栏位置

[按钮行]   [重置位置] 按钮（宽度 140px）
           说明文字：恢复到默认位置（右下角）
```

---

### 功能管理区块

#### 标题
```
功能名称：功能管理
```

#### 列表项结构
```html
[功能项行]
├── [拖拽手柄] ⋮⋮
├── [开关]
└── [文字区域]
    ├── 功能名称（粗体）
    └── 功能说明（小字）
```

#### 功能项配置

| 顺序 | 功能名称 | 功能说明 | 默认状态 |
|------|---------|---------|---------|
| 1 | 回到顶部 | 快速返回页面顶部 | 开启 |
| 2 | 模式切换 | 切换后台打开模式 | 开启 |
| 3 | 打开设置 | 打开脚本设置面板 | 开启 |

#### 拖拽手柄样式
```css
- 图标：六个点排列成 2×3 网格
- 尺寸：16px × 16px
- 颜色：var(--dnt-text-muted)
- 光标：grab / grabbing
- 悬停颜色：var(--dnt-text-secondary)
```

#### 拖拽交互
```css
- 拖拽中的行：
  - 透明度：0.6
  - 背景：var(--dnt-bg-hover)
  - 阴影：0 4px 12px rgba(0, 0, 0, 0.15)
  - 光标：grabbing

- 可放置区域：
  - 边框：2px dashed var(--dnt-primary)
  - 背景：淡绿色透明 rgba(103, 194, 58, 0.05)
```

#### 底部操作
```html
[按钮行] [重置功能配置] 按钮（宽度 160px）
         说明文字：恢复到默认开关状态和排序
```

#### 视觉效果
```
- 功能项行样式：
  - 内边距：14px 16px
  - 背景：浅灰色（var(--dnt-bg-section)）
  - 圆角：6px
  - 间距：上下项目间隔 8px

- 悬停效果：
  - 背景变深
  - 向右轻微位移（约 4px）

- 文字样式：
  - 功能名称：14px，粗体，主色
  - 功能说明：12px，次要色
```

#### 显示条件

| all | 全部后台打开 | 网格方格 | 所有链接后台打开 |

```html

```

## 动画与过渡

### 工具栏显示/隐藏
```css
@keyframes float-toolbar-in {
  from {
    opacity: 0;
    transform: translateY(20px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

动画时长：0.3s
缓动函数：cubic-bezier(0.4, 0, 0.2, 1)
```

### 按钮悬停
```css
过渡属性：background-color, transform, color
过渡时长：0.2s
缓动函数：cubic-bezier(0.4, 0, 0.2, 1)
```

### 拖拽动画
```css
拾取：transform 0.15s ease-out
移动：跟随鼠标，无过渡
放下：transform 0.2s ease-out
```

## 图标建议

使用 SVG 图标：

| 功能 | SVG 图标来源建议 | 备注 |
|-----|-----------------|------|
| 向上箭头 | Material Icons: arrow_upward | - |
| 齿轮 | Material Icons: settings | - |
| 拖拽手柄 | Material Icons: drag_indicator | - |
| 空心圆 | Material Icons: radio_button_unchecked 或 circle（stroke-only） | 用于 none 模式 |
| 横线列表 | Material Icons: list 或自定义3条横线（可选择右对齐、长度递减样式） | 用于 topic 模式，与现有悬浮球一致 |
| 网格方格 | Material Icons: grid_view 或 apps（2×2方格） | 用于 all 模式，与现有悬浮球一致 |

推荐使用 Material Icons 或 Lucide Icons，保持与现有悬浮球和设置界面图标风格一致。
